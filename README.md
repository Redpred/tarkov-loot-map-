# 塔科夫物资地图

面向《逃离塔科夫》的中文交互地图。探索 13 张地图的三维场景，出发前查物资、撤离点和任务目标。

**[打开在线地图](https://tarkovlootmap.com/)** · [查看任务](https://tarkovlootmap.com/tasks.html) · [获取 Windows 离线版](https://pan.quark.cn/s/336c5ebc25bc)

[![塔科夫街区完整三维场景的俯视预览](https://tarkovlootmap.com/previews/streets.webp)](https://tarkovlootmap.com/streets.html)

## 网页功能

- **查看楼层与地形**　在俯视、三维和第一人称自由飞行之间切换，用楼层预设与高度剖切查看室内。街区缩到最远时会自动居中显示全图。
- **查点位与测距**　按物资、容器、任务和撤离点等内容筛选。用底部「测距」在场景上标点，查看各段的三维直线距离。
- **准备任务**　查看前置关系，在「我的任务」追踪进度。任务详情和战前准备会提示适用的钥匙、门卡与进入条件，整项完成后会自动移出「我的任务」。
- **找回截图位置**　在对应地图选择「截图定位」，从游戏截图文件名读取坐标并标出位置。

## 体验方式

**网页**　选一张地图即可在线加载。支持目录授权的桌面浏览器可以指定本地资源目录，后续访问时复用已经保存的模型和贴图。

**Windows x64**　`1.4.0-alpha.20` 离线安装包约 1 GiB，预装 13 张地图的默认资源。安装与临时解压建议预留 10 GiB。

## 从源码运行

准备 Git 和 **Node.js 24.22.1**，在项目根目录安装依赖并执行源码测试。

```bash
npm ci
npm run test:portable
```

如果 Windows 的 PowerShell 包装脚本提示缺少项目运行时，将同版 Node.js 的官方 Windows x64 ZIP 解压到 `work/runtimes/node-v24.22.1-win-x64/`，让这个目录直接包含 `node.exe`。

运行完整地图需要匹配版本的外部数据、模型和贴图。准备资源后执行 `npm start`，访问 [本地首页](http://127.0.0.1:4175/)。现网使用原低档模型和原中档贴图，贴图长边上限为 128 像素。
