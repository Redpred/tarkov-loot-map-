地图资源包使用说明

1. 完整解压下载的 ZIP 到你选择的专用文件夹。不要改动 resources.json 和 blobs 文件夹中的内容。

2. 打开网站，在“设置 → 加载与缓存 → 本地资源包（只读兼容）”中点击“选择资源目录”。
   单张地图：选择含有 resources.json 的地图文件夹。
   全部地图合集：选择解压后的 maps 文件夹，其中包含各张地图的子文件夹。也可只选择其中一张地图。

3. 使用与 resources.json 中 quality 对应的模型和贴图画质（low 为低、medium 为均衡、original 为原始）。匹配的资源会从本地读取；缺少的资源会通过网络加载。网页、点位等其他数据仍需联网。

4. 网站只申请读取权限，不修改或删除这些文件。支持记住目录的浏览器下次可能需要重新授权；不支持的浏览器需进入地图页面后重新选择目录。

5. 清理时可先在网站“解除关联”，再自行删除不需要的地图文件夹；解除关联不会删除文件。如需自动下载和分类，请使用“设置 → 加载与缓存 → 资源保存位置”，网站会在专用子目录中保存资源，不修改原包。

如果提示未找到资源包，请确认已经解压，并选择上面说明的目录，而不是 ZIP 文件或 blobs 文件夹。
